What it does
Core Capabilities
🔍

New Launch Detection

Polls factory events via Clawby RPC (eth_getLogs) for brand-new tokens. Enriches creator with KOL check and tx counts across 5 chains.

🏆

Top 100 Ranking

Ranks memecoins by 24h volume with price, mcap, liquidity, holders, ETH in pool, and X buzz. Refreshes continuously.

🤖

AI Scoring (1–100)

Claude Code / Codex reads on-chain + holder + trading + social data and scores each token. Includes a 1–5 sentence rationale.

📄

Illustrated PDF Reports

Full PDF with price line chart, volume bars, holder-distribution doughnut, timeline, and total tx count — generated in 3–8 minutes.

⭐

Watchlist

Favorite any contract address. Per-CA refresh interval, KOL/smart-money counts, one-click deep analysis.

📱

Telegram Alerts

Optional bot integration. Fire an alert when an AI score clears a configured threshold. Per-chain alert settings.

🌐

Bilingual UI

Full English / 中文 support. Language picker on first open — entire interface switches instantly.

💾

Local Persistence

Favorites and every setting live in state.json. Fully restored on restart — no database required.
