Setup & Credentials
What you need to run it
🔑

Clawby API Key

Required

Sign up free at openclawby.com. Keys start with pk_. Handles all data: trending tokens, token info, holders, kline, X search, and all RPC calls. No Blockscout needed.

🐍

Python 3.9+

Required

run.sh creates a venv and installs fastapi, uvicorn, and httpx automatically on first run. No manual pip needed.

🤖

AI Engine

Optional
  • Claude Code CLI: claude logged in
  • Codex CLI: codex login or OPENAI_API_KEY

Required only for Windows ⑤⑥⑦ AI scoring and ⑧ deep reports. Monitoring (①②③④) works without it.

📱

Telegram Bot

Optional

Get a bot token from @BotFather. Configure in the Admin window: enter token, chat ID, and score threshold. Fires when any token exceeds the threshold.

🖥

Google Chrome

Optional

Required on macOS to render the report HTML → PDF. The AI generates an HTML report file; Chrome converts it to an illustrated PDF with charts.

📄 .env configuration
# copy from .env.example, then edit
CLAWBY_API_KEY=pk_your_key_here   # required, from openclawby.com
PORT=8799                          # optional, default 8799
⚡ Install & run
# 1. open the project folder
cd monhood

# 2. add your Clawby key
cp .env.example .env
#  → edit .env: CLAWBY_API_KEY=pk_xxx

# 3. run (first run auto-creates venv + installs deps)
bash run.sh

Then open http://127.0.0.1:8799 and choose your language. All settings (concurrency, mcap bands, scan intervals, Telegram) are configured in the ⚙️ Admin window and persisted to state.json.

⚙️ Admin settings reference
SettingNotes
Concurrency1-100, default 10, paired with a built-in ~6 req/s limiter
Report output dirWhere analysis PDFs are saved, default ./reports
Report language中文 / English, controls AI-generated report text
Analysis engineClaude Code or Codex, switch anytime from Admin
Per-window interval① 5s · ②④ 300s · ⑤⑥⑦ 600s, adjustable per window
Per-scorer mcap band⑤⑥⑦ each get independent min/max mcap + "created ≤ N days" filter
Launchpad togglesEnable/disable individual platforms Window ① listens to
Scan-field customizationTurn off holders/X/trading per-window to skip fetch & hide column (saves API quota)
